## 本版实现

- 1080×1920、30fps，六张完整原生项目卡，固定镜头、直接切换，开头直接讲第一个项目。
- 中文70px、英文64px；Pillow按文字实际墨迹边界测量，字幕与背景共用坐标，最多两行，中心Y=1580。
- 使用真实词边界生成字幕时间轴；透明间隔、逐段音画对齐、片尾0.8秒静默停留。
- 中文免费微软晓晓、英文免费Aria；不使用付费TTS或添加背景音乐。
- 本次中60.1秒/英64.4秒；53条实际解码字幕逐条比较、静态画面及音频验证通过。项目卡数字只代表原始截图时点。
