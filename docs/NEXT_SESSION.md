## 3. 需要单独明确授权的最小真实写入验收

本说明不授权发送邮件、评论、文章、更新资料或推送百度 URL。先完成只读验收；确需写入时，必须得到具体平台、账号、目标、内容、数量的一次性明确授权（不是批量推广授权）。验证码/扫码由用户完成，不绕过；不要用真实写入压力测试重试保护。

重点补齐“本次提交请求 -> 对应响应业务成功/ID -> 独立回读同一 ID”的关联。监听必须在点击前建立，检查精确目标与业务码；不能把任意 HTTP 200 当成功。使用实际脱敏响应，不臆造 action/schema。区分待审核、当前账号可见、公众可见、已发送与收件人送达、API 接收与搜索收录。

百度验证 HTTPS 接口与返回格式，不能降级 HTTP；部分成功不能重发整个批次。批次级防重不是逐 URL 的全球去重，必要时另做明确业务设计。
