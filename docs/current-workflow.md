# 当前推广操作入口

2026-11-20起收到用户指令再执行推广。先读主仓库 `docs/ai/promotion_operations.md`，再读本地策略 `activeContract`、最新日回执、效果数据和交接。历史定时轮留原始记录。

## 当轮执行

1. 先用 `check-consistency.js` 核规则、队列与日期，再用 `daily-execution-plan.js --as-of <ISO>` 看渠道缺口、结论待核与到期效果。效果复查读取最近两周的回执和日报以及最新原帖回查。后台已发且公开结果待核的作品也可按真实采样取数，发布精确时点缺失时沿用真实计数及采样时间。
2. 雷达中英各一期，抖音、B站、TikTok、YouTube各一条，X图文或视频择一。用6–8张真实原生卡和微软免费晓晓/Aria。先核近30天原仓库身份，允许同一期跨语言、跨平台分发。
3. 大AK在17:30后核当日原生三图，等19:30晚报实际生成再做当日整组三图。渠道为微博、头条、淘股吧，正文无产品链接，雪球暂停新增。非交易日注明实际报告日期。
4. 新稿先判断受众、任务、首屏、来源和质量。雷达首屏与首句先交代一个有来源的具体产物，检查成片的前两秒。大AK先写三图可核的当日现象，爱图先写可用图的具体场景和可替换提示词变量。按稿复审见 `docs/editorial-review.md`。
5. 爱图优先图库原图加完整提示词。全站功能目录、社区和低频渠道按实际机会维护。公众号和视频号用户手动，小红书、Capafy和旧警告期间的知乎暂停，Product Hunt暂缓，WorkBuddy后台由用户查。

## 工具与回查

- `daily-run.js --mode plan|build` 只用来计划或制作。按单稿调用 `publish-video.js`、`publish-ak.js` 等原生工具。具体命令见 `docs/radar-daily-runtime.md`。
- 当轮授权需要账号时，先探测固定Chrome资料目录的CDP，必要时启动该资料目录一次。核账号，按持久预留、CDP互斥、单次提交执行。遇账号验证停在相应页面。已有提交、上传结果不明或预约条目按原记录回查。
- 抖音核双封面已保存、原稿审核通过、公开设置和发布按钮。封面流量建议可忽略。TikTok核音乐版权与内容检查。
- 推广外链使用对应语言、渠道和具体内容的归因链接。雷达单榜用来源榜单，跨榜选题可指向一期内核过的项目详情。实时榜注明会更新。YouTube Shorts 文案给搜索指引，归因链接留作可点击频道入口的素材。
- 爱图演示已核实的模板时使用 `/aitu-studio/?template=<目录ID>`，接到该次真实演示。图库图文使用作品实际可访问的入口。发布前核文案、功能与入口一致。
- 汇报逐平台发布、审核、展示限制、未知和效果。按实际时龄采24h、72h和7d。延迟样本保留实际时龄，首屏试验沿用原样本要求。旧版视频、队列、审查与回执继续可读。
