# 每日例行清单

1. **Gmail 全量**（含垃圾箱）——账单/安全/审核/客户来信单独告知用户
2. **数据快照**：`node scripts/stats/daily-snapshot.js` → 结果记入本机台账
3. **百度推送**：10 条/天（无备案站配额），核心页优先
4. **反馈处理**：评论必回；质疑类评论=资产，真诚回应不辩解
5. **需求搜索**：`node scripts/reddit/demand-search.js "..."`，有价值才答
6. **分析+建议**：写入当日 STATUS 台账
7. **待用户事项**：先自查当前状态（登录态等），确认卡住才开口
